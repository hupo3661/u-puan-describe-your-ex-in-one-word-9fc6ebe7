One word for make.fun's "Describe Your Ex in One Word" bounty: a single-word verdict on an ex. The word is "Unsubscribed": the relationship, cancelled like a newsletter — no renewal, no reply, and no "we miss you" email bringing it back. `main.py` writes the word to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The word is written to `/output/entry.txt` (override with `OUTPUT_PATH`) and printed to stdout.
